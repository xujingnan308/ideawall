# IdeaWall 产品需求

## 产品定位

一个想法分享墙：所有用户把各自的短想法发布到一面公开的墙上，其他人可以浏览。
定位为技术栈验证 Demo，同时保证业务场景接近真实 SaaS。

## 目标用户

本 Demo 阶段：开发者本人 + 被邀请的测试用户。

## 核心功能（MVP）

### 浏览（公开，无需登录）
- 首页展示所有用户发布的想法列表
- 按时间倒序排列
- 每条想法显示：作者昵称、内容、发布时间

### 发布（需登录）
- 登录用户可以发布新想法
- 想法包含：内容（文本，有长度限制）
- 发布后出现在首页列表中

### 管理自己的想法（需登录）
- 登录用户可以查看自己发布过的所有想法
- 可以删除自己发布的想法
- 不能删除其他人的想法

### 认证
- 使用 Google OAuth 登录
- 支持登出
- 首次登录自动创建用户记录

## 不在 MVP 范围内

- 图片上传（后续再加）
- 点赞、评论
- 关注、私信
- 搜索、标签、分类
- 富文本编辑
- 举报、内容审核
- 邮件通知
- 管理员后台

## 页面清单

| 路径 | 名称 | 访问控制 |
|------|------|----------|
| `/` | 首页（想法列表） | 公开 |
| `/login` | 登录页 | 公开 |
| `/new` | 发布新想法 | 受保护 |
| `/my-posts` | 我的想法 | 受保护 |

## 数据模型（初版）

### User
- id
- email
- name（从 Google 资料拿）
- avatarUrl（从 Google 资料拿）
- createdAt

### Post
- id
- content（文本）
- authorId（关联 User）
- createdAt
